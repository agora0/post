神話上的美麗．第二十部份．命運ε

神話上的美麗．第二十部份．命運ε

B︰朋友，我其實一直並不喜歡海。

A︰為甚麼呢？

B︰或者和我差點死於溺水有關吧，哈哈，但是海的確不討人喜歡，我真的不喜歡海洋。海太大了，它深不見底，它沒有任何方向，它沒有前後左右。任何陸地的生命不慎跌入都會被其無情吞噬，海對人類來說其實並不友好，你說對嗎？

A︰能理解。

B︰就算人們能造船，但船也只是一片漂流在無限恐怖之上的小葉子，看不到岸邊的大海可能比沙漠還可怕。

我有一個長輩是海員，是我的舅舅。

我舅舅有時會和我提起，某一個認識很久的人在海上精神出問題了，某一個人抑鬱焦慮陷入奇怪的幻想，在遠海討生活的人們可能會自殘甚至自殺。

更可怕的是，有的人突然有天就在船上失蹤了，怎找也找不到這人。

可能是自殺，也可能是他殺，

船上還可能流傳是冤魂索命、精怪附身、異國邪神，像是恐怖故事是嗎？

B 摸了摸鼻子。

B︰朋友，說實話，我其實有時懷疑我的舅舅也早瘋了，只是他沒有表現得很明顯。

聽我的舅媽說，舅舅會有時自己一個靜靜地待著發呆，像是缺了一點靈魂與生命的氣息一樣，沒有人知道他在想甚麼。

大概是舅舅從小和我比較親，有一些海上的事就只和我說。

舅舅常年出海賺錢，我的舅媽只需要打理家裏的事，她是一個虔誠的信徒，積極地參加教內的活動，這有時多少害苦了我那可憐的表弟表妹。

神明對我的舅媽來說不止存在，也必須存在。有一次舅舅坐的船出了嚴重的事故，死了人，舅媽認為是她一直的祈禱起了作用，是神明保佑了她的男人保佑了她的家庭，在舅舅大休期間舅媽就拉著舅舅天天去祈禱還神，舅舅覺得煩，卻也沒有拒絕自己的妻子。

抱歉，我會不會也講太多令你覺得有點煩了？

A︰不會，我的朋友。

B︰所以從小到大我就不喜歡海，海邊對我來說並不是甚麼浪漫想像和度假勝地，是寒冷黑暗缺乏人性的未知潮濕，它或者對你沒有惡意，但也絕對沒有任何善意，像是夢遊的鯨魚一邊睡覺一邊將路過的小魚小蝦吞入腹中，它不知道你的存在，你的生死也與它無關。

我也從不喜歡水族館之類的地方，人們總是覺得水族館這種水母很漂亮，那種魚沒有見過很奇妙。

但對我來說，水族館的動物像是活在和人類完全平行的世界，小狗小貓和一些陸地動物都能對人有反應，海裏的生物呢？遇到人或者就逃開，或者就殺死你，又或者不自覺地毒死你。我的確欣賞不來。

海洋很美麗嗎？或許吧，但那並不是和人類親和的美麗。

A︰朋友，聽你說話，令我想起一個關於海洋的故事。

B︰來吧，我就知道你講故事的癮是時候發作了。

如此 A 回憶了一個關於海洋的神話。

很久很久以前，

人們其實並不像現在這樣生活在陸地上，

遠古的人們是兩棲的生命 (ἀμφίβιος = ἀμφί + βίος = amphibious)，

醒時生活在陸地，

夢時潛睡在海裏，

居無定所，

隨著季風與海流在世界不停遷徙。


別的生命問人類︰

人類啊，你們這樣在世界無止境地漫遊，

由一地去到另一地，

是為甚麼呢？


那時的人們回應︰

我們羨慕和渴望能像鳥類那樣飛翔，

那是夢中的神明輕輕吟唱的搖籃曲 (καταβαυκάλησις = singing a lullaby)。


其他生命問︰

神明對你們說了甚麼嗎？


人們回答︰

神明對我們說，

擁抱天空 (Οὐρανός = Ouranos)，

觸摸自由 (ἐλεύθερος = liberty)，

新生的孩子 (παῖς = child)。


其他生命又問︰

你們人類真是奇怪呢，

你們沒有一個屬於自己的地方嗎？

你們沒有家嗎？

人們困惑地想︰

家？甚麼是家？

在那時，生與死，醒與夢之間的界限是模糊不清的。

對那時的人們來說，

一代人出生，又一代人死去 (Θάνατος = Thanatos = Death)，

就是一代人醒來，又一代人睡去 (Ὕπνος = Hypnos = Sleep)。

人們兩棲於陸地與海洋，

人們兩棲於清醒與夢中 (ὄνειρος = Oneiros = Dream)，

人們分不清兩者有甚麼區別，也不會去分。

醒時遇到的偶然與必然，

夢裏遇到的偶然與必然，

並沒有甚麼不同。


如是者，

一代代人綻放，

一代代人凋零，

醒時會有人在思考甚麼是家，

夢中亦有人在追問甚麼是家。

一代又一代，不知道過了多久，

這個問題成為了代際間未眠的迴音 (Ἠχώ = Echo)。


因著對「家」的注意與好奇，

人們不知不覺地，

開始在夢中向神明祈禱，詢問甚麼是「家」。


虔誠的祈禱，凝聚出各人的禱告，

這些大大小小的禱告彼此擁抱，

成團的探險，

從淺海到深海，

從光照幽微到黑暗，

在冰冷的海水中，

尋找傳說中那深不見底的深淵 (ἄβυσσος = abyss)，

聽說真正統治海洋的神明就棲息其中。


人們醒來後，

忘記了自己在夢中賦予氣息的祈禱。

他們只是有一個微弱的印象，

好似自己詢問過甚麼問題。


星辰旋轉，

過了不知道多久，

人們的夢中流傳著一個新的傳說。

那個前所未聞的傳言說，

有一隻美麗的白牛從深海的末端出生。

然後越來越多的人們說自己看到了那傳說中的白牛。


「噢！白牛原來真是真的！」

於是在海中發現白牛的人們就在後面跟著那奇蹟的生物，

不斷有新的見證者加入這個越發龐大被好奇充盈的隊伍，

人們想看看，

美麗的白牛到底想去哪裏，

有沒有最終的目的地 (τέλος = telos = destination)。

有人忍不住問白牛︰

美麗的白牛，你到底要去哪？你是在尋找甚麼嗎？


白牛說︰

我夢到了美麗的七色彩虹 (Ἶρις = Iris = Rainbow)，

在夢中，天穹的彩虹在對我唱歌。


人們又問︰

原來你想找在天空的彩虹，

那我們不會飛，我們到時還可以跟著你嗎？


白牛說︰

我也不知道呢。


和白牛一同在夢中的人們沒有再問，繼續默默地跟著。

不吵不鬧，像守序的魚群一樣，

他們圍繞著發光的白牛旋轉，有規律地來回游動。


光與影交替，

又過了不知道多久，

白牛說它聽到了巨大的聲音，

它慢慢向上游，

離開了深海，

離開了淺海，

最後脫離了海面，

呼吸到陸地的空氣。

眾多的人們追隨著白牛來到岸上，

他們看到暴雨下的大地有一道可怕的巨大裂縫 (χάσμα = chasma = rift)，

似是被從未見過的閃電擊中，

留下的焰火在水滴下也沒有熄滅。

白牛在此時似乎失去了所有力氣，

四足跪地，呼吸越來越稀薄。


人們問它︰

你怎麼了？你生病了嗎？我們要不要回到海裏？


白牛回答︰

謝謝你們，

但我應該快要死了，

我的生命正在不停地流逝，

或者這裏就是我的終點 (τέλος = telos = destination)。


人們問︰

那彩虹呢？

你不是說要找到彩虹嗎？

我們還未看到彩虹。


白牛說︰

親愛的朋友，

我還能聽到彩虹的歌聲 (ᾠδή = ode = song)，

或者最後一段路了並不能用身體到達，

你們能把我送到彩虹身邊嗎？

這是一個約定。


人們問︰

我們要怎麼做呢？


白牛說︰

請你們的領唱者為我裝扮，

我們將共浴於潔淨的清水，

再將金箔貼上我巨大的角，

然後把無力的我放置於香木之中。


人們問︰

這樣就可以了嗎？


白牛說︰

噢，

請你們的領唱者在歌聲與舞蹈中，

取得那在雨水下仍不熄滅的火焰，

再將我與香木一起點燃，

我將成為無形煙火，

在神明的見證之下，

帶著我們的祈望一起看到彩虹。

請答應我們之間的這個誓約 (ὅρκος = oath) ，

我最好的朋友，我生命旅途忠誠的同伴。


人們問︰

可是，那樣的話，你會死的。


白牛說︰

親愛的朋友，

我已離開家太久，

我也需要回家了。

請答應我，

我成煙後，

分食我的血肉，

這將成為我們共同的回憶，

世代相傳的印記。

而我留下的骨頭，

和那抹金箔的角，

請千萬不要取走，

將它們組成好看的樣子，

於那裂縫下沉到海水中，

我的靈魂將隨著它回家 (νόστος = nostos = homecoming)。


人們不解︰

家？甚麼是家？

它是甚麼地方？


白牛說︰

你們不知道嗎？


人們答︰

我們不知道呢。


白牛說︰

那請你們將世界上最長的繩子綁上我的白骨，

當繩子完全靜止時，

你們就知道我回家了。


人們又問︰

那甚麼是家呢？


白牛答︰

親愛的朋友，

回家和家是同一件事的不同說法。

只要你們感受到繩子完全靜止，

當知曉我已回家那一刻，

你們也一定會明白甚麼是家。


人們再問︰

那我們呢？

你死了我們該去哪裏呢？


白牛說︰

我也不知道呢，

或者你們可以在我回家後，

等等看天空的彩虹有沒有出現，

向神明祈禱，

再想想你們要去哪裏。

很抱歉，

我無法帶著你們看到真正的彩虹 (Ἶρις = Iris = Rainbow)，

也無法邀請你們回到我夢境開始的地方。

若果你們想念我的話，

可以看看摸摸那繩子，

那是我安息的墓碑和象徵 (σῆμα = sema = sign, mark, tomb, monument)，

是我和你們仍然參與的記憶 (μνήμη = mneme = memory)，

也是神明應許的奇蹟 (θαῦμα = thauma = wonder)。

願神明保佑你們。

人們哭著笑著，

如約地在香木中燃燒了白牛，

白牛不痛也不叫，

只是看到人們為它哭泣，

它也流下了最後的淚水。

從未見過的大火，

驅逐了黑暗與寒冷。


人們在仍在燃燒的烈火中，

小心地取出白牛留下的白骨，

角上的金箔沒有脫落，

反而融入了整對牛角，

讓之有著純金的光輝。


在世界上流浪的其他人們，

在遠處看到巨大的火焰，

成為這個祭禮最後的參加者，

他們被邀請見證 (μάρτυς = martyr = witness)，

白牛的骨頭是怎樣從裂縫潛回深海。


人們看到，

那世界上最長的繩子，

如脫水的魚兒一樣，

在干燥中不停抖動，

每一刻都發出聲音，

晝晝夜夜亦不停息。

日月升降，

生死輪轉，

沒有人知道又過去了多久，

可能是幾代人？也可能是十幾代人？

在誓約之下，

那已成為傳說的繩子仍被人們守著。


直到有一個多數人仍在睡夢中的黎明，

繩子突然不再發出任何聲音，

靜止了下來。

早已告別兩棲的生活，

不在海中入夢的人們，

看著黎明微弱的彩虹，

擁抱著，顫抖著，

依照和白牛終末的約定，

將它彼端不可見的遺物，

紀念命名為 錨 (ἄγκυρα = anchor)。

那就是人們對白牛最後的記憶。
