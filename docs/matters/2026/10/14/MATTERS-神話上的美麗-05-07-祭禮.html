神話上的美麗．05-07．祭禮

Oct 14, 2026 • Drunken 🍺

神話上的美麗．第五部分

B 和 C 看著 A 拿出手機，在他們面前輸入了一些沒頭沒尾的句子，這大概就是 A 的「筆記」。

在這個過程中，就在旁邊的 B 看到 A 手機上記著一句：

Φύσις κρύπτεσθαι φιλεί

自然喜愛隱藏自身

Nature loves to conceal itself.

B： 你筆記上的這句是甚麼意思？

A： 這句是說「自然喜愛隱藏自身」，據說來自古人赫拉克利特 (Heraclitus = Ἡράκλειτος)。

B： 我聽過他的名字，但對他不太了解，印象中他很喜歡說一些沒頭沒尾的句子。對我來說，他這句「自然喜愛隱藏自身」改成「赫拉克利特 (Heraclitus) 喜愛隱藏自身」也無不妥。

C： 他讓我想起了我們文化中的一些詩人 (ποιητής = poet)，那些詩人寫的句子也如同謎語一般。

B： 說實話，我無法欣賞這種如謎語般的美學 (αἴσθησις = aesthetics) 與哲學。

C： 為何呢？

B： 我比較喜歡清晰的表達。在我看來，模糊與謎語只是對語言和邏輯掌握不夠充分的表現。很多問題並非沒有解答，而是語言上的定義還不夠清晰；一個問題若在語言上定義不清，自然就不可能會有準確的答案。基於這一點，雖然我欣賞一些詩人，但我也衷心慶幸詩人不會統治我們。在我們的世界裡，理性依然佔據上風。

A： 這真是有趣的見解。

B： 你不認同我所說的嗎？

A： 我的朋友，我只是對「詩人不會統治我們」這個說法感到有趣。

B： 這為甚麼會令你覺得有趣呢？詩人不會統治我們，難道不是一個顯而易見的事實嗎？難道在你的文化中，詩人曾經成為過統治者 (ἄρχων = archon, ruler)？

A 似乎又走神了片刻。

A： 我的朋友，你所指的「統治 (ἄρχω = arche = rule, beginning, principle, source)」是甚麼意思？

B： 就是字面上的意思，「統治」還能有其他甚麼意思嗎？

在旁的 C 似乎想起了甚麼。

C： 在我的文化中，詩人的確曾經成為過統治者。

B： 這真令我驚訝。

C： 那是發生在很久以前的一位君主身上的事，關於他的歷史記載很少，我們只知道他喜歡寫下如謎一般的詩句。他的女兒也是一位詩人，和她的父親一樣喜歡寫謎語般的詩句。很可惜，這對父女的詩句並沒有多少在時間的長河中被保存下來。

B： 世界真是無奇不有！神話愛好者，你對此沒有甚麼想說的嗎？

A： 這令我想起一個希臘詞語 νόμος (nomos = law, custom, melody, rhythm)；這個詞有「習俗」的意思，也有「法律」的意思，同時它亦有「旋律」的涵義。

B： 然後呢？

A： 詩人寫下的詩歌旋律成為了習俗，人們的習俗又化作了法律；於是，詩人便成了君主，或者說，這也是自然 (φύσις = physis, nature) 的一部分。

B： 朋友，對我來說，你這個聯想有點牽強了。

A： 那你認為該是怎樣的呢？

B： 一個詩人如果能成為統治者，那麼這位詩人必定在以下幾方面佔據優勢：或是武力，或是家世，或是財富。詩人無法單憑寫詩就成為統治者，而是因為他已經具備了統治的條件，才成為了統治者。我不認為那些成為統治者的詩人是因為寫詩才統治的，寫詩大概只是他們的愛好而已。

B 轉向了 C，問道：

B： 這位朋友，你覺得呢？

C： 我覺得你說的也有一定道理。我也很難想像詩人能單靠詩歌就令人服從；沒有一定的自願服從，也就沒有統治。

B： 或許在神話故事中可以吧。我們的神話愛好者朋友在你來之前，就講了一個將詩人與國王相提並論的神話 (μῦθος = myth)。

C： 真可惜我錯過了。

A： 我的朋友，需要我再回憶一次嗎？

C： 不用，不如你就從還未完成的地方繼續說起吧？

A： 這對我來說真是一個難題，因為在我的記憶中，這些神話都是未完成的。請容我回憶一下，看看我能在這些迷霧中觸及到哪些碎片。

等待了一會兒後，B 和 C 聽到了 A 的回憶。

詩人的女兒發現她年邁的父親最近鬱鬱寡歡。她未曾察覺到任何緣由，老父親似乎自從獨自遠行歸來後便一直如此：精神萎靡，沉默寡言，極少會見朋友，亦未曾再寫下半句詩行。

更令她鬱悶的是，老父親竟然扣了她的零用錢。

為此，她作了一首歌，並親自填上了歌詞。

詩歌的內容諷刺她的父親對可愛的女兒吝嗇至極，卻對一些只見過幾面的朋友借錢不還之事不聞不問。可憐的女兒勞苦功高，卻不得不節衣縮食。眾神的天使聽到女兒正義的泣訴後都評論道：無論依照哪一個國家文化的習俗與律法 (νόμος = nomos = law, custom, rhythm)，都不該有如此行徑；快快歸還女兒本該擁有的零用錢。

這首古靈精怪的詩歌成功逗笑了年邁的詩人父親。他笑著說：「這都寫的甚麼亂七八糟的東西，盡不學好！叫你少吃點甜食你不聽，看看你的牙齒都快壞掉了。」

原本老父親還想多訓斥幾句，說些甚麼「好好學習，詩歌在文法上固然可以有更大的彈性，但絕非毫無文法 (γραμματική = grammar)；不要辜負神明賜予你的天賦 (φυΐα = phyia, talent)，你的天賦在我的眾多學生中都是極為罕見的」之類的話。但他似乎突然想起了甚麼，沒有再說下去，只是給了女兒一個無奈又寵溺的笑容後，便將她打發走了。

費盡心思的勞作終於得到了回報，女兒從父親那裡拿到了一個盒子。這是她從小到大最愛玩的遊戲：父親會拿出幾個盒子讓她挑選，她只能選一個作為禮物，且每個盒子裡裝的東西都不相同；在打開之前，她無從知曉裡面究竟藏著甚麼。

從小到大，她拿到盒子後從不會急忙打開，這是她對待所有禮物的態度。她只有在為神明獻上供奉祭品 (θυσία = thysia = offering)、表達了對神明的感恩之後，才會輕啟盒蓋。

她之所以這麼做，是因為她幼時立下的誓言 (ὅρκος = horkos = oath)。

在她很小的時候，她曾向神明祈求，希望能有一個真正的家 (οἶκος = oikos = home)，有愛護她的親人，讓她不再是一個無人問津的孤兒。若神明願意實現她這個微不足道之人的願望，她將在未來接受每一份美好、每一件禮物之前，都先向偉大的神明獻上供奉與感恩。

神明垂聽了她的願望。當年邁的詩人父親帶著學生路過她出生的城鎮時，收養了她。

在完成了一番對神明的感恩與供奉後，詩人的女兒打開了盒子。

她發現裡面放著一顆寶石，頓時欣喜若狂。

她在第一眼便深深著迷了。這是父親送給她最貴重的禮物 (δῶρον = gift)，最重要的是，這也是她最喜歡的禮物——並非因為這顆寶石看似價值連城，而是因為它散發著一種無法以言語形容的美麗 (Κάλλος = Beauty)。

女兒陷入了恍惚之中，耳畔彷彿響起了一段古老的歌謠：

幽暗裡永恆樂章的半個音符，

叩響了微小的我那死寂的心弦。

感謝神明，有幸讓凡人學會如何哭泣，

讓淚水的漣漪，能觸及那無形美麗億萬分之一的微光。

詩人的女兒就這般哭泣了整整一夜，全然未曾察覺時光的流逝。

徹夜未眠的她，在清晨的第一縷晨光中，前往了一座她常去的神廟。她傾盡了所剩無幾的零用錢，獻上了她力所能及的最豐厚的祭品。

得到寶石的第三天，她帶著父親最愛吃的食物去看望老父親，並對父親說，以後不必再買這麼昂貴的寶石給她了。

卻沒想到，老詩人父親的反應十分愕然。

父親： 寶石？甚麼寶石？

女兒： 就是那顆很漂亮、很美麗的寶石呀。

父親： 但我沒在盒子裡放寶石啊！

女兒： 不要再逗我了！真幼稚！

老詩人猶豫了好一會兒，才對女兒說：「哦，我又想起來了。給我看看，看它配不配得上我的寶貝女兒。」

女兒： 你可別借機把它拿回去。

父親： 我才不會做這種幼稚的事。

女兒： 你就會。

經過一番交涉後，女兒才將放在新盒子裡的寶石拿了出來。

老父親在盒子裡看不到任何寶石，卻只看到可愛的女兒滿臉笑容地期待著讚美。

老詩人最後只是笑著說了一句：「很適合妳。」

深怕老父親把寶石收回去的女兒，轉眼便一溜煙地跑掉了。

又過了幾日，老詩人親手焚毀了自己諸多視為心血的詩作。幾位一直陪伴在側的學生苦苦勸阻，卻也無濟於事。

得知此事後，女兒哭著問父親為何要這麼做，那可都是他的畢生心血。

老詩人看著蒼老了許多，卻一掃之前的鬱鬱寡歡。他只說自己想寫些新的東西，並未作過多解釋。老詩人看著哭泣的女兒，鄭重地要求她答應幾件事：

第一，永遠不要將那顆寶石示之於人；

第二，她日後用心創作的詩歌，只能在密友之間流傳；

第三，她必須隱藏自己的美麗與天賦。

女兒不明白父親為何要提出這些要求，她只是流著淚緊緊抱住父親，答應了他所有的條件，並阻止父親繼續焚毀自己的詩稿。

老詩人輕撫著女兒說，她便是神明賜予自己最珍貴的禮物；日後女兒在向神明獻祭供奉時，可以連同他那一份也一併獻上。這也是他要求女兒答應的最後一件事。

又過了一段不算太長的時日，老詩人就過世了。

神話上的美麗．第六部分

聆聽完 A 回憶的這段神話後，B 對於其中涉及獻祭供奉神明的部分不吐不快。

B： 我無法認同神明存在的其中一個關鍵原因，在於祂們竟然需要人類的獻祭 (θυσία = thysia = sacrifice, offering)。

C： 我的朋友，可以更詳細闡述你的觀點嗎？

B： 首先，在諸多宗教的描述中，神明皆是至高無上的存在，居於遙不可及的天界，享有凡人無法想像的榮華福樂。既然如此，為何掌控天界的神明會需要必死凡人 (βροτός, θνητός = mortal)的獻祭？祂們甚麼都有，擁有的東西遠比凡人更好，祂們真的需要凡人的祭品嗎？這就如同一國之君竟需要一隻小貓捕獲的魚兒一般荒謬。這是第一點。

C： 還有呢？

B： 其次，某些人認為透過獻祭可以換取神明的寬恕。我曾見過重罪之人，用不義之財購買昂貴的祭品來祈求赦免。若此邏輯成立，那麼他人是否也可以用不正當的手段奪取這些罪犯的財富，將其一半獻祭，一半自用？若神明能被金錢收買，神明真的神聖嗎？如果神明能被金錢驅使，那我們的宗教組織需要的就不是信徒，而是對沖基金。

C： 你說得很有道理。

B： 再者，當不同信仰的人們交戰時，雙方都會向各自的神明獻祭。難道戰爭的勝負取決於誰的供品更多？既然戰爭必有勝負，那麼神明豈非對失敗的一方失信？這些矛盾足以說明獻祭行為的非理性本質。

C： 那麼依你之見，人們為何要進行獻祭呢？

B： 我認為獻祭本質上是一種群體性的心理安慰機制，類似安慰劑效應 (Placebo Effect)。信眾透過獻祭，建立起付出與回報的心理期待。當好運降臨時，他們便歸功於神明的庇佑；而面對不幸時，他們又會以「神明的懲罰」、「供奉不足」或「天意難測」等非理性概念來自我安慰。這與迷信賭博致富無異，只是人們選擇性地將好事歸功於神明，而對壞事則尋找各種藉口來解釋。

C： 那你認為獻祭神明真的毫無意義嗎？

B： 也不能說完全無意義，安慰劑效應 (Placebo Effect) 也是一種效應。

B 沉思片刻，繼續說道。

B： 同時，宗教獻祭不僅是個人行為，更是凝聚社群的紐帶，它是社會秩序的基石。歷史上一些獻祭儀式與農業社會的豐收季節相互呼應，孕育出我們今日所享的諸多節慶，這些節慶都為我們的生活注入了無可替代的文化活力。即使我並不信仰任何宗教，不信仰任何神明，但我也無法否認自己喜歡各種節慶。

C： 所以朋友你的觀點是：獻祭雖然在神學層面上難以立足，但在社會層面上卻發揮著積極正面的作用？

B： 正是如此。我甚至懷疑，古代一些祭司也曾有過相似的想法；他們或許並非真正相信獻祭的神效，而是認為獻祭的主要價值在於社會的凝聚。

C： 你說的這些見解在古代恐怕會招致危險。

B： 確實如此。這等言論在古時無異於褻瀆神明、叛逆傳統、違背先知律法。輕則被逐出族群，重則可能招致殺身之禍。朋友，在你的文化中也是類似如此吧？

C： 是的，雖然我們這邊宗教對政治的影響力相對較小，但這種挑戰傳統的言論同樣會被視為不敬神明，會對人們立足於他們所在的社群產生負面影響。

B： 還有一個現實層面的考量，供品經濟也是一種經濟。若說供品毫無意義，神廟賣的各式各樣供品又該如何維持？這可是一條綿延千年的產業鏈，我這些說法是在動搖這條產業鏈上的人實實在在的利益。有趣的是，我觀察到許多信徒心裡也認為供品未必真有效用，但就像購買可能永遠用不到的保險一樣，買了只是給自己一份心安。

B 又頓了一頓。

B： 而對於一些社會來說，有些供品獻祭儀式已經成為該社群傳統文化的一部分。單單說供品沒有作用，並不會影響人們是否繼續他們的宗教行為，因為這已成為他們群體文化認同不可或缺的組成部分。

B 留意到 A 只是在聆聽，而沒有表達任何意見。

B： 這就是我對獻祭大概的看法。神話愛好者，你對此沒有甚麼想法嗎？

A： 噢，我的朋友，我覺得你說得很好。

B： 你不能只說句我說得很好就略過這個話題，起碼你要說說你的看法，畢竟我也很有興趣知道。

A 猶豫了一下。

B： 這難道對你來說是一件很難的事嗎？

A： 我的朋友，你的期待對我來說的確有一定難度。

B： 為何？

A： 我不知道該從甚麼地方說起。

B： 你這一刻想到甚麼就說甚麼好了。

A： 我一直對獻祭的問題充滿疑問，我從未想清楚到底甚麼是獻祭，我也不知道從哪裡開始回答你的問題，因為我認為我對此的知識十分有限。我想起我曾經就獻祭的問題請教過一位祭司；我不太完全記得我和這位祭司交談的內容，但我會努力將我能記住的部分分享給你，我的朋友。

B： 好。

A： 我記得那位祭司說，獻祭是否有效是一個很複雜的問題。

B： 然後呢？

A： 那位祭司說，要簡單回答這個問題比較困難；不同的人問這個問題，會得到不同的回答。

B： 為何會如此呢？難道那位祭司對這些宗教問題沒有一個統一的答案嗎？

A： 我的朋友，我也曾問過那位祭司為何不同的人會得到不同的回答。那位祭司說，不同的人的詢問源於不同的意圖，不同的意圖需要有不同的回答；同時，任何關於神聖的問題本質上都有多層次的答案，不同的答案有時並非互相矛盾，而是一個答案不同層面的不同分支。那位祭司說，作為凡人，本質上難以接近更深層次的答案；這是凡人詢問神聖時必須在心中保持的謙卑，以免落入 ὕβρις（hubris：對神明僭越的傲慢）的詛咒。

B： 我沒有想到你詢問的這位祭司和我一樣也是一位不可知論者 (Agnostic = ἀ + γνῶσις = without + knowledge = 無 + 知識)。那你能總括一下你得到的回答嗎？

A： 那位祭司說，對於我這個信仰神明的凡人來說，獻祭有效與否取決於我自身。如果我能在獻祭時保持虔誠並盡力保持對 德性 (ἀρετή = arete = virtue) 的凝視，那可以認為大部份獻祭是有效的，只是有效程度不等。

B： 對我來說，這聽起來像是安慰劑效應 (Placebo Effect) 的另一種說法。你有沒有問那位祭司，為何神明需要祭品呢？

A： 有的，我的朋友，我問既然神明完美無缺，為何需要凡人的獻祭。那位祭司問我，我相信的神明是否完美無缺？我回答說是。那位祭司繼續說，如果你信仰的神明是完美無缺的話，那麼並不是你信仰的完美無缺的神明需要凡人獻祭，而是凡人需要獻祭來接近神明。那位祭司說，對於我來說，我的情況是神明不需要獻祭，但我需要獻祭。

B： 我不太明白，這聽上去像是「社會需要獻祭儀式來維持凝聚力」的一種變形說法。

A： 我的朋友，我和你一樣有不少疑問。我記得那位祭司還說，我的情況是我的情況，其他人的情況並不一定適用；希望我不要把對我適用的當成絕對的普遍。但對神明獻祭時保持虔誠，凝視 德性 (ἀρετή = arete = virtue)，是在大部份情況下都適用的。我至今仍未想清那位祭司是甚麼意思。

B： 這也太奇怪了，難道不同的人還要有不同的獻祭方式嗎？如果宗教儀式不統一，那麼還有甚麼意義？宗教儀式必須保持一種統一。

A： 我覺得那位祭司不是這個意思。

B： 那在你的理解下，應該是甚麼意思呢？

A： 我的朋友，至今我也不認為我完全理解了這些，我無法回答你啊。

B： 那位祭司還說了甚麼嗎？

A： 我記得在交談中有過一段話，大意是：「如果你宣稱你信奉某一位神明，你最好真心相信那位神明真實存在。如果你對一位神明進行獻祭，那麼你最好相信那位神明一直注視著你，你的選擇將決定你的命運。」

B 笑了一笑。

B： 對我這個不信任何神明的人來說，這才是最有難度的。即使我參加一些傳統的節慶祭典，我也只是當作走一個大家都認可的流程，而我並不是唯一這樣想的人。我認為在節慶祭典上獻祭於神既然已成為傳統文化的一部分，那保留下來也沒有問題；只是我真的很難對之有甚麼虔誠的心理狀態，更難真的相信背後有甚麼神明的存在在接收祭品。

B 看到在一旁的 C 在思考著甚麼。

B： 我的朋友，你在想甚麼呢？

C： 我只是突然記起我的一個朋友。我那個朋友對這些宗教的儀式都十分注重，都以很虔誠的態度去面對；我在這位朋友身邊時，總是能感受到一種宗教的氛圍。

B 好像想起了一些趣事，又笑了起來。

C： 我的朋友，你想起了甚麼嗎？

B： 我想起了我國家的一個政治人物，我曾近距離看到這位政治人物參加傳統祭典。這個政治人物素有虔誠的名聲，在各種媒體中總是被渲染成復興我們國家古老宗教傳統的使者。但我親眼看到的卻是這個政治人物並不熟悉一些儀式中的流程與手勢，還不時做錯。對我這個成長於宗教學校的人來說，實在很難裝作看不見。

B 攤開雙手，做了一個無奈的表情。

B： 對我來說，宗教也只是一種政治的工具。作為無神論者，我不能理解為何到了這個時代，宗教竟然還能有這麼強大的政治吸引力，使得一些政治人物必須要往自己的身上貼上虔誠的標籤來獲得巨大的政治能量。我能退一步，接受現實是這些不理性的力量仍然在塑造權力的天際線；但這樣也越發令我難以對神明與宗教泛起任何的敬意，因為神明也淪為了政客在歡樂舞台上擺弄的道具。

B 繼續以一種諷刺的語氣說道。

B： 我常常想，這些實際上世俗化 (secularization) 得比誰都深，卻在表面上裝成虔誠信徒的政治人物，在私下會如何看待那些因為信仰而支持自己的人？我覺得，其中也必定沒有甚麼敬意存在；畢竟這是一種愚弄的關係，而愚弄的關係能存在真誠的敬意嗎？我們「偉大」的傳統宗教真要在這些表裡不一的人手上「復興」嗎？我想，還是算了吧。我寧可接受老一輩的古板教士為我上課，我不知道我的國家未來會再墮落成甚麼畸形的神話生物。抱歉，想起這些我就忍不住不停地抱怨。我的朋友，不知道在你的國家有沒有類似的情況？

C： 在我的國家，傳統上大家都不敢違背對神明的誓言 (ὅρκος = horkos = oath)，認為這是極大的罪行。我國家的政客多多少少都有一種迷信，覺得這種表裡不一真的會冒犯到神明，所以倒沒有太多你提到的做法。同時，在我的國家，傳統宗教還頗有活力，實在不需要甚麼政治人物用虔誠的名義去「復興」傳統宗教。

B： 這令我驚奇。我以為你的國家和我的國家一樣，完成了普遍的世俗化 (secularization)。

C： 其實在一些方面我的國家還是很世俗化，這或許和我所在文化的歷史有關。我所在文化的祭司會因為傳統宗教禁忌還是其他原因，令祭司和世俗權力若即若離；這些祭司似乎有意和世俗政治保持距離。我一直以為這是普世的常態，直到長大後我去不同的地方，才發現世界上有的地方祭司深入地涉入了政治，就和朋友你的文化一樣。

B： 老實說，我也曾以為我文化的宗教政治關係是普世常態，長大後才知道並非如此。

C： 我曾在一些國家看到人們深恨宗教，這對我來說也是相當陌生的認識。因為在我的文化中，宗教雖或時不時有醜聞與腐敗，但總體來說人們對其的印象仍是良好的。我們大都相信神明的存在，並不是因為宗教強力地涉入政治，而是因為在我的文化中，宗教在歷史長河中留下過很多有價值的東西。我們文化的很多人都認為這是神明對我們的禮物，我們也欣然參與節慶對神明獻祭。

B： 我不羨慕你們仍有宗教，但我得承認，我羨慕你們沒有對宗教的仇恨。在我的文化裡，世俗權力、宗教權力、平民階級之間的衝突實在太多了。我活在一個世俗權力與平民階級取得上風的時代，實在不願那些宗教權力再度捲土重來；我的意願是如此，但似乎在我的國家，很多人並不這樣想。至今我仍無法理解這些人們的想法，即使其中有的人是我的家人。我有的家人在以往對宗教並不熱衷，近年卻投入各種「復興」運動，我真的無法理解他們；他們對傳統宗教的認識甚至沒有我來得深！他們真的知道自己在「復興」甚麼嗎？我不知道如何和他們進行這些敏感的話題，我害怕影響我們的關係。我嘗試理解他們，但我失敗了。我只能看著這些家人支持那個連傳統儀式都做錯的虛偽政客。在家人的聚會上，我們都對任何宗教政治的議題有意地避而不談。

神話上的美麗．第七部分

B 說完後，聽到有人出言反對，這聲音卻並非來自 A 或 C。

D： 恐怕我無法同意你剛才說的內容，你的言論帶有相當大的偏見與錯誤。

B 轉身，看見穿著一身傳統教士服飾的 D，下意識地雙臂交叉，姿態顯得相當防備。

D： 你如此否定傳統、崇尚現代，又如何確信你現在所信奉的思想就是正確的呢？

B： 確實，我無法確信。但是，我會盡可能地思考、質疑並調整我的觀點。不同於宗教教條的一成不變，我的世界觀允許自我修正。我實驗、我觀察、我改進，這正是科學精神的核心。我根據可觀察的事實理性行事，而非將意志寄託於虛無縹緲的古代神話。傳統宗教在理性的現代科學面前節節敗退，這不正是其有效性缺失的明證嗎？

D： 現代科學並非萬能，你所推崇的現代理性本身亦有其局限。你以為自己已洞悉了世界更深一層的真相，但很可能你只是盲人摸象，觸及了冰山一角便誤以為已掌握全貌。科學主義 (Scientism) 只在特定的領域與範圍內自洽有效，然而人們無法單純從科學中尋得生命所有的答案。近年來宗教思潮再度興起，為何？這是你無法否認的事實，宗教的能量並非如你所想的這般簡單。

B： 對你這樣的教士而言，這想必是令人欣喜的發展吧？在你們看來是復興，在我看來卻是退步。我必須承認，我低估了愚昧無知的力量，低估了人們對迷信的渴求，沒想到心理與精神安慰的巿場竟是如此巨大。但這些終究只是迷信，是建立在無法證實的神話之上的空中樓閣。它們如夢幻泡影，如海市蜃樓，經不起嚴謹的推敲，終將也經不起時間的考驗。

D： 這正是迷信現代性 (modernity) 所帶來的災難！你指責我們的傳統宗教禁錮了人們的思想，難道你不也被你所信奉的現代性所禁錮嗎？你對神話不屑一顧，但現代性 (modernity) 本身，或許只是另一種人造的神話 (myth)。若你細心回顧歷史，就會發現科學發展的進程中同樣有著許多虔誠的信仰者；歷史遠比你那簡單的「現代進步史觀」所認為的要豐富多彩得多。

B 沉默不語，依然交叉著雙臂。

D： 看看現今這個世界吧：到處都是金錢至上的資本主義與消費主義；舉目皆是冷冰冰的工業化與標準化；向上望去，是如怪物般的官僚體系；點綴四周的，是將一切意義還原為原子與數字的科學主義、娛樂化與膚淺化的大眾政治、缺乏深度的文化，以及賣弄新造詞彙的廉價現代知識分子。生命的意義究竟何在？人越來越像機器，人的價值甚至還不如沒有生命的機器。你們自以為在追求進步，但那只是一個幻覺，你們不過是在追逐名為「現代性」的時尚潮流。蒼白的現代性平庸，只能用如吸毒般短暫的享樂來對抗，卻注定徒勞無功。你們創造出畸形的怪物，又為它無知的生命奉獻出了所有。

B： 這種論調我在國內早已聽過無數次，毫無新意。你們總是對古代懷有難以證實的美好幻想，認為凡是古代的、凡是傳統的都是美麗的。若古代真如你所言般美好，古人的平均壽命就不會如此短暫。你們總是將對古代的美夢投射到歷史詮釋上，但古代的殘酷難道就缺席了嗎？你說古人樸素純粹，然而古人殺嬰屠城時也毫不手軟。這些在現代社會絕對是戰犯的行為，在古時卻是人人稱頌的英雄事蹟。難道這就是你們崇古派教士所要推行的「古代道德」？

B 揮了揮手，繼續說道：

B： 你說現代人道德墮落至極，難道你們教士階層就不墮落？這甚至不需要舉現代的例子，熟讀經文律法如你，也知曉經文中對此有著諸多記載。那些經文中描述的古代祭司、教士、國王、貴族難道就不貪財好色？難道就全都敬畏神明？若你認為信仰宗教、尊敬神明就不會道德墮落，那你就是在反駁你自己所信仰的經文！「古代是黃金時代」不過是另一個神話罷了。現代或許不如我們想像中完美，但其進步也遠超古代！我實在無法理解那些動輒主張復古的人，他們真的知道自己在復活甚麼嗎？回到幾百年前就一切安好？哈！真是天真得可愛！

D： 我的族人，你也熟讀經文，卻為自己的立場而曲解其意。教士或許在道德上有所墮落，但這與不信神明所帶來的災難性墮落，在本質上是不同的。

B： 兩者有何區別？我實在看不出來。

D： 神與人的位置顛倒了！這種影響遠比你想像的要深遠！

B： 哈，這絕對是件好事。

D： 你不懂！孩子，你完全不懂！神必須被置於首位！人必須居於神之後！這是最大的區別！這種顛倒，比某些教士的道德墮落要嚴重得多！

B： 真是瘋狂！當我需要食物時，難道我不去尋找能為我烹飪的人，反而去祈求神明賜予？當我渴求知識時，難道我不去請教老師，反而去祈求神明啟示？若神明真能回應人的一切需求，為何我族在歷史長河中屢遭慘敗，頻遇天災？哦，你會說這是神對人的懲罰，人必須繼續相信神！

B 帶著厭惡的語氣說道。

B： 不，我們不需要神，也不需要神的幫助，我們只需要人。是人幫助了人，也只有人能幫助人；神大可安居天界永不下凡，這才是世間的最佳秩序！從古至今，是人類自己一步步從石器時代走到今天；即使曾經需要神來提供心靈慰藉，如今也已完全沒有這個必要！人類自己就能開創自己的道路，文明只會愈發進步！

D： 對我而言，這才是最大的瘋狂。你根本不明白自己在說甚麼！你們將摧毀自己文明的根基，你們甚至可能為人類帶來滅絕。難道一次比一次更可怕的戰爭，沒有讓你們反思？難道科技發展到人類憑一枚炸彈就能抹去數十萬甚至數百萬生命，沒有讓你們感到恐懼？時代真的在進步嗎？抑或是在倒退？為何科技如此發達，貧困人口依然眾多，饑餓仍未消除？為何科技無法阻止仇恨，你們讚頌的現代先進思想無法制止政治的愈加瘋狂？你們難道不反思嗎？若現代性真如童話般美好，為何發展至今，仍有如此多人生活在現世地獄之中？

B： 我們會反思，但我們不需要神來指導我們反思。人總有各種私念，但我們不需要一個私念無限大的神！

D： 你們既然信奉科學，那若你們的前提就是錯誤的，又如何能得出正確的推論？若神明確實存在，你們一切的假設都將淪為笑談。

B： 若神明確實存在，那就證明給我看！神在哪裡？告訴我，神在哪裡！我看不見，摸不著，聽不到。看吧，你們甚麼都證明不了，卻要求人們盲目相信。哈，這不是天大的笑話嗎？

D： 你們總認為人類能解決一切，憑藉人的理性便能克服所有難題；只要給你們足夠的時間，就會創造出烏托邦般的文明。不，我告訴你們，事實並非如此。無論科技發展到何種程度，無論你們所謂的現代政治思想更新到何種版本，無論人們對現代性的追逐演變成何種難以想像的形態，你們認為的美好世界烏托邦都不會到來！

B： 我們不需要絕對完美的未來，我們只求相對更好的明天。現在或許尚不夠美好，但未來必有實現之道。過去饑餓奪走無數生命，如今越來越少人因饑餓而死；過去多數人目不識丁，如今文盲率持續下降，教育日益普及；文明是實實在在地在進步，你無法否認這些！

D： 在你所謂那相對美好的未來到來之前，恐怕你得先祈禱人類不要自我毀滅。你們不是認為人類普遍理性嗎？那人類又怎會自我滅亡呢？

B 深深吸了一口氣。

B： 我認為群體間仇恨的根源之一，正是宗教本身。

D： 這是何等的偏見！

B： 這不是偏見，而是最真實的事實。你認為我族的宗教傳統是最正確的，對吧？

D： 當然如此，我為此感到自豪。你不應拒絕自己的傳統，沒有它就沒有我們，沒有它也就沒有你。

B： 你認為我們的宗教傳統最為正確，而我們的敵國同樣認為他們的宗教傳統最為正確，這不正是仇恨的源頭嗎？

D： 並非所有人都得到了真神的眷顧。

B： 你的意思是我們得到了真神的眷顧，而我們的敵人沒有？若你如此認為，那我同樣可以主張，其實是我們的敵人得到了真神的眷顧；否則你看，上次戰爭我們是如何慘敗的？我們敗得多麼徹底。

D： 荒謬絕倫！胡說八道！我難以置信這些惡毒的言論竟出自我的族人之口！你到底明不明白自己在說甚麼？

B： 哈，這你就無法接受了嗎？既然真神站在敵人那邊，何不我們舉國改信敵國的信仰？或許下次戰爭我們就能扳回一城？

D： 如此不敬神明！無神論已毒害你至深！真是無可救藥！

B： 我深愛自己這片土地的文化，但我不愛我文化中那些只存在於神話故事裡的神！我只愛我能見到的人！這樣就算無可救藥嗎？你才是無可救藥！

D： 你不懂！你真的不懂！你不明白一個文明文化的真正根源！

A 和 C 注意到 D 正艱難地壓抑著自己的怒火。

D： 我為在外族友人面前失態深表歉意。我向你們兩位保證，我們的文化傳統絕非如此不堪。我希望你們有朝一日能造訪我們的國家，去看看那些尚未被現代性 (modernity) 侵蝕的地區是何等熱情好客。

B： 夠了！也許我和你都是個笑話。我們國內的政治有多混亂，明眼人一踏上國土便一目了然，不必再對外族友人說這些表面話了。你說我不知道一個文明文化的真正源頭；我承認在過去，我們的先知、我們的祭司、我們的貴族肩負著文化傳承的責任，但一個文明文化的真正泉源，只能是該文明的所有人民！先知已不在了！祭司已不在了！貴族已不在了！你們這些教士在未來也將與世俗學者無異。到那時，我們文明的文化依然會傳承下去。客觀地說，你們終將消逝，而歷史的巨輪仍會滾動。

B： 或許你們現今仍能影響某些政客以左右時局，但那也救不了你們。人生不應只有神，人生不應只為神，這是包括我在內的許多人所嚮往的美麗未來。你們想像中的美麗我們不需要；你們或許很認真地在做一些你們認為是正確的事，但歷史會證明你們是錯誤的，希望你們早日接受這一事實。

B 情緒激動地說完這些，深吸了一口氣，轉向 A 和 C。

B： 很抱歉，我得先行離開了，我在鎮上還會停留一段時間，有機會再與你們交談。

B 離開後，A 和 C 注意到 D 臉上流露出深深的失落表情，並聽見 D 輕聲自語。

D： 孩子們為何就是不懂呢？他們會毀滅自己的；沒有神，他們會毀滅自己的。孩子們並不相信。老師，我不明白，我已盡力保持耐心；老師，我想盡我所能，但無論如何都做不好。孩子們始終不理解，孩子們只相信他們自己。神啊，我該怎麼辦？為何人世間充斥著如此多虛假的希望？為何人間充滿著不可避免的災難？神啊，我的神啊……

這份失落對 C 來說相當陌生，C 從未在自己的國家見過如此悲傷的教士。
