神話上的美麗．第十三部份．世界α

聽罷 A 對「幸福 (εὐδαιμονία)」的闡釋，B 帶著幾分醉意問道。

B： 這便是你們部落對幸福 (εὐδαιμονία) 的定義嗎？你們在定義一個詞彙之前，總要先講述一段故事？還是說，這種說文解字的方式僅是你個人的習慣？是你的性格使然？

A： 噢，我的朋友，這兩者並不衝突。這是我從部落繼承的不成文習俗 (νόμος = nomos = custom)，是我部落的風氣 (ἦθος = ethos = custom)，亦是我個人所恪守的習慣 (ἦθος = ethos = habit)；或者也可以說，這是我們的文化傳統。

B： 這是你們文化的傳統？

A： 是的，我的朋友。我們的文化認為，每一個字詞皆有其生命，而每一個生命，皆有其故事。我們以故事來詮釋字詞，便是向其他生命引薦這個字詞的生命。這是對字詞之生命 (βίος = bios = life) 的讚美，亦是在觸摸它們的氣息 (πνεῦμα = pneuma = breath, spirit)，感受它們的韻律 (ῥυθμός = rhythmos = rhythm)。

B： 你們的文化在我看來實在有些奇特。而且，我沒想到你竟是個保守派。

A： 保守派？我的朋友，為何你會說我是保守派呢？

B： 好吧，嚴格來說，我在你身上並未察覺到那種刻板的「保守派」氣息。但在我看來，你是一個極為尊重傳統的人——不僅是口頭上說說，在日常生活中亦是依循傳統的方式行事。你應該不會否認這一點吧？

A： 我不否認。

B： 若從這個角度來看，你不是保守派還能是甚麼呢？如果你不喜歡「保守派」這個詞，我也可以改用「傳統派」。雖然我知道這其中還有五花八門的細微區分，但此刻我們不過是隨意閒聊，倒也不必作如此細緻的辨識，無須真去將完整的社會光譜剖析出來。

A： 可是，我的朋友，X 曾經對我說過，我像是一個顛覆者。

B： 顛覆者？你是顛覆者？這可真奇怪。那 X 還說了你甚麼？

A： X 說在我身上感受到了同類的氣息，而 X 自稱正是一名顛覆者。

B： 真是有趣。那麼朋友，你又是如何看待你自己的呢？你認為自己是甚麼人？你認為自己究竟是誰？

A： 我的朋友，我曾極為認真地思索過這個問題。很可惜，正如許多其他問題一樣，我至今仍尋不著更深層的答案。我曾聽人說過，認識自己，或許是一件比想像中艱難得多的事。

B： 那我問你，如果我給你幾個選項：「我是保守派」、「我是顛覆者」、「我不是保守派」、「我不是顛覆者」。這四個選項，你會選擇哪一個？

A： 我能選「我不是保守派」和「我不是顛覆者」這兩個嗎？

B： 你怎能這般選呢？這是在作弊！你只能選一個。

A： 那我能四個同時都選嗎？

B： 這是遊戲規則，而規則是不容許你全選的！

A： 我的朋友，我是真的不知該選哪一個。或許你可以考慮改變一下遊戲規則，讓我起碼能選三個？

B： 不行！這倒令我想起了一個故事，故事裡也有一個甚麼都想選的人。

A： 是甚麼樣的故事？

B： 哈，沒想到現在竟輪到我來講故事了！那是一個關於蒙眼人的故事。

在某個偏遠的小鎮裡，住著一個奇怪的人。這個怪人無論是待在家中還是外出，都會用布蒙住自己的雙眼。

旁人問那個蒙眼人：「你整日蒙著雙眼，你真的能知曉自己身處何方嗎？」

蒙眼人回答：「其實早在很久以前，我便已不知自己身在何處。蒙眼與否，於我而言已無太大分別；蒙著雙眼的我不知自己在哪，不蒙雙眼的我，同樣不知自己在哪。」

旁人便說，這真是一個怪人，他恐怕是染上了某種奇疾。

某日，一位看似貴族的人路過這座偏遠的小鎮。這位貴族從鎮民口中聽聞了這個奇怪的蒙眼人，便親自登門拜訪。

看似貴族的人： 你為何要蒙住自己的雙眼呢？

蒙眼人： 因為我不知自己身在何處，但我又渴望知曉自己究竟在哪。

看似貴族的人： 你蒙著雙眼，又怎能知曉自己在哪呢？

蒙眼人： 我老師的老師的老師曾說過，這世上有些人，即便蒙著雙眼，也能洞悉自己身處何方。

看似貴族的人： 所以你將自己的雙眼蒙上，以為這般便能成為那樣的人？

蒙眼人： 我老師的老師的老師說，此舉並不能使我們成為那樣的人，但這樣做能讓神明知曉我們渴望成為那樣的人。如你所見，我至今仍未成功，神明亦尚未眷顧於我。

那個看似貴族的人覺得十分有趣。

看似貴族的人： 在這個國家裡，只可能有一人，能在蒙住雙眼時亦知曉自己身在何方。

蒙眼人： 敢問那人是誰呢？

看似貴族的人： 唯有一個國家真正的國王，才能在蒙著雙眼時，依舊知曉自己身在何方。

看似貴族的人見蒙眼人陷入沉默，未作任何回應。

看似貴族的人： 你沒有甚麼想說的嗎？你不質疑我的話嗎？

蒙眼人： 我認為你所言確有可能，故而不作質疑。

看似貴族的人： 那你知道我是誰嗎？

蒙眼人： 實在抱歉，我不知你是誰。

看似貴族的人笑著說：「我便是那個蒙著雙眼，亦能知曉自己身在何方的人。」

沒想到，蒙眼人依舊沒有任何回應。

看似貴族的人： 你為何又不說話了？你相信我就是那個人嗎？你是選擇相信我，還是不相信我呢？

蒙眼人： 我能兩者皆選嗎？

看似貴族的人： 兩者皆選是甚麼意思？

蒙眼人： 我選擇相信你，同時也選擇不相信你。

看似貴族的人： 你不能這般選擇，這既不合邏輯，亦不合規則。你只能選相信，或者不相信。

B： 我只記得這些了，我的朋友。

A： 朋友，這真是一個巧合，恐怕我曾聽過這個神話。

B： 真的嗎？那你知道這個故事還有後續？

A： 噢，有的，這個神話確有後續。

B： 那蒙眼人到底選擇了甚麼？

蒙眼人並沒有立即作出選擇。

蒙眼人反問了那個看似貴族的人一個問題：「請問，『唯有一個國家真正的國王，才能在蒙著雙眼時亦知曉自己身在何處』這個說法，你是從哪裡聽來的呢？」

看似貴族的人： 為何這不能是我自己想出的說法呢？

蒙眼人陷入沉默。

看似貴族的人： 好吧，我承認這確實不是我自己想出的說法，這是我從我祖輩的祖輩的祖輩那裡聽來的。我已經回答了你的問題，那現在，你能告訴我你的選擇了嗎？

蒙眼人： 我依舊選擇你給予我的全部選項。

很多很多年後，蒙眼人也收了自己的學生。

最年幼的學生： 老師，現在您能蒙著雙眼，也知曉自己身在何方了嗎？

年老的蒙眼人： 傻孩子，我做不到這一點。

最年幼的學生： 一個國家真正的國王也不能嗎？

年老的蒙眼人： 或許能，或許不能。

最年幼的學生： 老師，您這答了跟沒答一樣，我也知道人不呼吸便會死呀。

年老的蒙眼人： 我們又不是國王，更非真正的國王，你知曉這答案又有何用？

最年幼的學生： 我想知道答案，因為我也要當蒙眼人。

年老的蒙眼人： 傻孩子，我們蒙住自己的雙眼，並非因為國王，而是因為暴君 (τύραννος = Tyrant)。

最年幼的學生： 暴君？暴君與我們有何干係？

年老的蒙眼人： 暴君成功地做成了一件事。

最年幼的學生： 暴君成功地做成了甚麼事呢？

年老的蒙眼人： 暴君成功地迷路了。暴君成功地做到：每一刻睜開雙眼，卻依然不清楚自己究竟處於世界的哪個角落。暴君在「睜眼」這件事上極其勤勉，他們時刻保持警醒，不間斷地驅逐著與睡眠 (Ὕπνος = Hypnos = Sleep) 相關的神明。

最年幼的學生： 那這與我們蒙眼又有何關聯呢？

年老的蒙眼人： 迷路之人無法抑制對奇蹟 (θαῦμα = thauma = wonder) 的渴望；而深陷巨大的迷途，更是無法抑制將奇蹟 (θαῦμα = thauma = wonder) 化為可見與龐大之物的渴望。

最年幼的學生： 為甚麼呢？

年老的蒙眼人： 因為奇蹟 (θαῦμα = thauma = wonder) 能夠定標方位。奇蹟 (θαῦμα = thauma = wonder) 並非單純的死物，亦非可供人隨意擺弄的果實。奇蹟 (θαῦμα = thauma = wonder) 是有生命的，其生命蘊含著大自然的暗示；這種會呼吸的暗示，能映照出一個靈魂 (ψυχή = psyche = soul) 所處的方位。

最年幼的學生： 然後呢？

年老的蒙眼人： 極其巨大的迷途，便需要極其巨大的可見標記來定位。然而，孩子，詭異之處在於，奇蹟 (θαῦμα = thauma = wonder) 這種生命，似乎天生便畏懼宏偉。當面對龐大而可見的宏偉事物步步進逼時，奇蹟便會迅疾地逃逸。

最年幼的學生： 那這究竟與我們蒙眼有何干係呢？

年老的蒙眼人： 這是一項古老的習俗 (ἦθος = ethos = habit)，亦是一個古老的不成文約定 (νόμος = nomos = custom)。相傳，一個地方蒙眼的人若越是真誠，奇蹟 (θαῦμα = thauma = wonder) 便會認為周遭並無巨大可見的宏偉事物在逼近，於是，奇蹟們便能在此地安心地多逗留片刻。這是一種祈請的儀式，是一份美好的希冀，是自漫長歲月前便一直延續至今的願望。

最年幼的學生感覺老師又在誆騙自己，頓時哭得像個孩子——當然，他本來也就只是一個孩子。

年老的蒙眼人看著這一幕，笑得十分開心。

X： 你知道的，有些官宦子弟特別有統治階級的意識；他們覺得自己的認知水平就算及不上最核心的那批聰明人，但在家庭教育與成長環境的耳濡目染下，認知的層級水平總歸比一般人要高。因而他們覺得自己天生就是做媒體的料，到處找人幫他們寫東西。

X： 然後？我一個好管閒事的無聊朋友，覺得我不應該天天喝酒墮落、餓死自己，最後落得個屍體在精神病院火化的下場，於是就把我推了出去，這群喜歡當媒人的聰明傢伙。

X： 這不是為了讓你有互動的感覺嗎？這是開放式的劇情，這世界並非只有一個終點，這或許也算是一種「自由」。

A： 我的朋友，我想知道，E60 這個孩子相信神明的存在嗎？

X： 這當然不，這是甚麼愚蠢的想法。

A： 但你不是說 E60 認為自己擁有天賦嗎？

X： 為何你要將「擁有天賦」和「相信神明」關聯起來呢？這對我來說是一件很奇怪的事。

A： 噢，我的朋友，或許這個世界所有的天賦，都是一種神明賜予的禮物 (δῶρον = doron = gift)。

X： 不同的人總有不同的天賦。要是神明得為這些人一一分配好禮物，你不覺得神明有點太忙了嗎？說起神明，或許我知道這個故事該怎麼講下去了。

E60 所在的國家裡，有的人相信神明存在，有的人不相信神明存在。

有意思的是，相信神明存在的人，並不會比不相信神明存在的人更容易承認自己的錯誤。

根據 E60 的觀察，按照那個幼稚的「桌子錯誤理論」分類法，在信神的人與不信神的人當中，每一類人的比例其實是差不多的。

E60 想起了一些自己看過的宗教文化習俗。

在一些文化中，每一年都會有幾個特別的日子。

在這些特別的日子裡，祭司會挑選一些有生命的、活著的祭品。這些祭品代表了整個族群、部落、城邦、民族、國家的集體罪行。

這些代表著集體罪行的「祭品」可能是動物，也可能是人。

在經過一輪儀式後，這些活的「祭品」可能被放逐，也可能被處死。

在「祭品」被放逐或處死後，集體的「罪行」就被儀式性地、象徵性地「祛除」了。

你不覺得這些很有意思嗎？我的朋友。

人們知道自己在犯錯，人們知道自己有罪，人們知道每個人都有罪，人們知道罪行是「污穢」的。

然後人們選擇一些「祭品」獻給神明，好像這麼做之後，「污穢」就被淨化掉了，罪行也得到了和解與赦免，責任似乎就這樣被轉移了。

朋友，我記得你之前提過一個與「污穢」類似的詞。那個詞是甚麼？我不太記得了。

A： 我的朋友，可能你說的是 μίασμα 這個詞。它的意思是污穢不潔 (μίασμα = miasma = pollution / defilement / stain)。它帶有一種非物質的意涵，代表著一種精神性的、非物質的、不可見的不潔與污穢，而且它還有一定的傳染性。

X： 對，就是這個詞。很有趣不是嗎？為甚麼污穢與不潔會與「可見」、「不可見」聯繫起來呢？你知道為甚麼嗎？

A： 我的朋友，我也不清楚其中更深層的意思。

X： 朋友，你想想。如果一個「東西」，或者說「存在」是「不可見」的，它又如何會被認知或理解成「污穢不潔」呢？

不潔與污穢在起源上，是一種與「視覺」、「嗅覺」更為相關的詞。既然人們無法看到「污穢不潔」，也無法聞到「污穢不潔」，那這件「概念中的事物」又是如何被認知為「污穢不潔」的呢？

你說是也不是？

A： 噢，我的朋友，你說的有道理。

X： 那朋友，你有沒有想過，執行這種群體性「贖罪」、「替罪」儀式的人們，按照 E60 的「桌子錯誤理論」，到底算是「哪一類人」？

算是第一類「知道自己錯誤，對自己承認自己錯誤，也對他人承認自己錯誤」的人嗎？

那「知道自己錯誤，對自己承認自己錯誤，也對他人承認自己錯誤」的人，為何「要由他人來承擔自己錯誤的後果」？

在「贖罪」、「替罪」的儀式中，儘管每個人都向所有其他人承認了自己犯錯，但既然每個人都在承認自己錯誤，那似乎就沒有人需要對自己的行為負起真正的責任；最後，就只能由動物或者一些邊緣人來承擔這種集體的罪惡，好像放逐或殺死這些「祭品」，就能真的將「污穢不潔」消除掉。

那這到底算是第一類、第二類，還是第三類？每個人都好像承認了自己有錯誤，但又好像沒有一個人真正對自己和他人承認了自己的錯誤。這很奇怪，不是嗎？

或許我知道該怎麼將故事寫下去了。

E60 從小到大都在想，為何人們需要這種「贖罪」、「替罪」的儀式。

對於這個問題，E60 一直沒有找到一個真正令自己滿意的答案。

直到 E60 遇到了自己那位瘋狂的老師。

或者這位瘋狂的老師，就稱之為 W02 吧。

有 W02 就有 W01，W02 是 E60 的老師，而 W01 則是 W02 的老師。

E60 的一生，幾乎都活在 W02 的陰影、庇護、恩澤與恐懼之下。

A： 我的朋友，我想問，為甚麼 E60 作為 W02 的學生，會活在對 W02 的恐懼之下呢？

X： 這世界上總有一些比較奇特的師生關係，恐懼與被恐懼也是一種關係。W02 並不是甚麼正常的人，更不是甚麼正常的老師。難道你沒有真正恐懼的事物，真正恐懼的人嗎？

A： 噢，我的朋友，我沒有真正恐懼的人，但我有真正恐懼的事。

X： 我懷疑你說你沒有真正恐懼的人。人總有自己恐懼的人、事、物。在這個世界上，人總會有自己的敵人，有些敵人甚至可能是天敵。就如同動物的世界一樣，從出生的那一刻起，你就可能已經與世上的某些存在為敵了。

讓我把故事繼續講下去吧。

E60 毫無疑問地覺得自己是有天賦的人。

然而，E60 的老師 W02，則是 E60 見過擁有最可怕天賦的人。

W02 是天生的操縱者，是天生的統治者，是天生的法律與規則制定者。

在很長一段時間裡，E60 都認為自己的老師受到了上天的偏愛。這世界從來都並不公平，這是相當明顯的事；若有任何人公開宣稱自己能帶來絕對與無限的公平，那這個人一定是一個善於操控的人。

在 W02 晚年半瘋之後，E60 覺得，或許任何的祝福，都伴隨著詛咒——既是祝福也是詛咒，既是詛咒也是祝福。

或許正如朋友你曾提到過的那個「藥毒同一」的詞一樣。

那個詞我記得是 φάρμακον (pharmakon = remedy / poison)；它同時擁有解藥、毒藥兩個意思。既是解藥也是毒藥，既是毒藥也是解藥。

「藥毒同一」這個詞 φάρμακον (pharmakon) 令我印象深刻。或許，人們只會記得對自己有意義的詞，人們只會記得對自己有意義的名。

朋友，斯蒂芬·茨威格 (Stefan Zweig) 在他的著作《斷頭王后》(Marie Antoinette) 中有那句廣為流傳的名言：
