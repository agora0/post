#投稿者：sven

作为一个资深且常年直面最终用户的 IT 一线工作者，有些不得不说“内部资料”。

首先，没有计算机就没有 IT 这个部门，所以这个部门产生的历史没有那么久。比起其他部门来说，IT 部门是一个“拧巴”部门：权利/责任/利益极不对等。除了少数计算机相关产业的公司，IT 部门的收入一般来说是比较少的，同等职级下，HR/销售/财务/市场/营运等部门的收入都高于 IT 部门。但是 IT 部门的权力和责任又是不成比例的更重的。比如，上到 CEO，下到实习生，所有的权限都必须由 IT 部门来管理，所有人在公司电脑上的操作，以及任何连接公司内部网络的设备，例如 iPad 或者个人手机等，无差别的被 IT 部门所监控。

说句题外话，一般在大型公司上班的人都知道，入职第一天，你会去 IT 部门领一台工作用的电脑，可能是笔电，也可能是台电。你可以把这台电脑想象成你租的一间小公寓，而且周围是四面透明的玻璃的那种，我的意思是，千万不要在工作电脑上做太多私人的事宜，尤其是一些比较隐私或者私密的，例如访问成人网站之类的，有巨大的社死风险，你的一举一动全部都被 IT 部门尽收眼底。只是大部分情况下，不涉及到违反公司规定的事宜，IT 部门也都是睁一只眼闭一只眼，毕竟大家都是同事一场。

说到责任，IT 部门可就更大了，如今大型企业的所有内部数据全都是数码化的，所以公司的数据安全也是 IT 部门考核的重中之重。但是搞笑的是，虽然大型公司都会投入大量预算采购各种尖端的硬体和软体以保障公司的网络安全和数据安全，每一个具体的员工却可能因为自身的一时疏忽，导致整个安全体系的轰然倒塌。

举个例子，有的员工习惯把自己的帐号密码写在post-it 纸上或者笔记本上，然后又在公司内部或者外部随手一放，被别人轻而易举的获取，然后黑客或者商业间谍就能利用这一关键信息，窃取公司的资料或者攻击公司的整个网络系统。因此有时候针对普通员工的 IT 基本安全培训也是十分必要的。当然一旦发生了这样的事情，IT 部门绝对是第一个背锅的。

另外，大部分公司使用的系统还是 Windows，纯使用 Mac OS 的企业毕竟是极少数，因此一旦微软（创造并持续维护 Windows 系统的公司）由于发布的系统补丁造成系统出现 Bug，例如无法开机或者系统突然变得很卡，出来背锅的依然是 IT 部门，虽然实际上并不是 IT 部门能够控制的，但是需要向前来投诉的普通员工或者管理层解释的依然是可怜的一线 IT 人员们。虽然感觉还有很多可以写的内容，但是还是就此打住吧。最后教所有非 IT 办公室职员一个处理任何电脑问题的万能小妙招，就是“遇事不决先重启”。
